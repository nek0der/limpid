# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful. Assume good intent. Keep discussions focused on the work.

To report a Code of Conduct concern (harassment, abusive behavior, etc.), contact the maintainer directly at the email address on their [GitHub profile](https://github.com/nek0der). Do not use a Discussion for this: GitHub Discussions are public. Security vulnerabilities have a separate channel; see [SECURITY.md](SECURITY.md). We respond within a few days.
